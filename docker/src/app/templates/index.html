pytbak API

Welcome to the pytbak API. This API allows you to manage contexts.

This application serves as a versatile testing tool, a "swiss army knife" for backend experiments. It provides a set of simple, well-defined API endpoints for various functionalities, including CRUD operations, performance testing (Fibonacci calculation, sleep delays), and direct interaction with services like Redis. It is designed to be a reliable and observable backend for prototyping and testing infrastructure, security policies, and client applications.

For detailed API documentation, please visit the API Documentation page.
